고객지원

자주 묻는 질문을 먼저 확인하시고, 해결되지 않으면 아래 양식으로 알려 주세요.

자주 묻는 질문

음성 인식이 안 돼요 / 글자가 안 적혀요
  1. 휴대폰 설정 → 애플리케이션 → 말비서 → 권한에서 마이크를 허용해 주세요.
  2. 음성 인식은 휴대폰의 Google 음성 인식을 사용해요. Play 스토어에서 Google 앱을 최신 버전으로 업데이트해 주세요.
  3. 인터넷 연결을 확인해 주세요.
  4. 회의 기록 화면의 음량 막대가 움직이지 않으면 마이크 소리가 들어오지 않는 것이에요. 다른 앱이 마이크를 쓰고 있지 않은지 확인해 주세요.
회의 기록 중에 받아쓰기가 멈췄어요
기록 중에는 화면이 꺼지지 않도록 유지돼요. 다른 앱으로 전환하거나 화면을 직접 끄면 받아쓰기가 멈출 수 있으니, 기록하는 동안에는 말비서 화면을 켜 두세요. 멈췄다면 계속 버튼을 눌러 이어서 기록할 수 있어요.
녹음 파일도 저장되나요?
아니요. 말비서는 음성 원본을 저장하지 않고, 텍스트로 받아쓴 내용만 저장해요.
회의록 요약은 무료인가요?
네. 기본 요약은 무료이며 휴대폰 안에서 처리돼요. 설정에서 본인의 Claude API 키를 등록하면 더 자연스러운 AI 요약을 쓸 수 있고, 이때 비용은 본인의 Anthropic 계정에 청구돼요.
다른 휴대폰에서도 내 메모와 회의록을 볼 수 있나요?
네. 같은 이메일로 로그인하면 메모·회의록·일정이 자동으로 동기화돼요. Claude API 키는 보안을 위해 휴대폰마다 따로 입력해야 해요.
일정 알림이 오지 않아요
  1. 휴대폰 설정 → 애플리케이션 → 말비서 → 알림을 허용해 주세요.
  2. 배터리 절약(최적화) 설정에서 말비서를 제한 없음으로 바꿔 주세요.
  3. 일정을 다른 휴대폰에서 만들었다면, 알림은 일정을 만든 휴대폰에서 울려요.
비밀번호를 잊어버렸어요
앱 로그인 화면의 비밀번호 찾기에서 가입한 이메일을 입력하면 비밀번호 재설정 메일이 와요. 예전에 아이디로 가입한 계정은 메일을 받을 수 없으니, 로그인 후 설정 → 이메일 등록을 먼저 해 주세요. 로그인도 안 된다면 아래 양식에서 계정·데이터를 선택하고 아이디를 적어 보내 주세요.
비서에게 말로 일정을 추가할 수 있나요?
네. 비서 탭에서 이렇게 말하거나 입력해 보세요.
  • "내일 오후 3시 치과 일정 추가"
  • "금요일 10시 반 주간 회의 잡아줘"
  • "다음 주 월요일 아침 9시 보고서 제출 일정 등록"
비서가 날짜와 시간을 확인해 드리면 "네"라고 답하면 저장되고, 알림도 자동으로 예약돼요. 시간을 말하지 않으면 오전 9시로 정해요.
삼성 캘린더나 카카오톡으로 일정을 보낼 수 있나요?
일정 탭에서 일정을 누르면 아래에 두 버튼이 있어요.
  • 휴대폰 캘린더에 추가: 삼성 캘린더·구글 캘린더의 일정 추가 화면이 열려요. 그 앱에서 저장을 누르면 들어가요.
  • 공유: 카카오톡, 문자, 메일 등으로 일정 내용을 보낼 수 있어요.
말비서 일정과 휴대폰 캘린더는 자동으로 연동되지 않아서, 나중에 말비서에서 일정을 바꾸면 휴대폰 캘린더에서도 직접 고쳐 주세요.
회원 탈퇴는 어떻게 하나요?
앱의 설정 → 회원 탈퇴에서 바로 할 수 있고, 모든 데이터가 즉시 삭제돼요. 자세한 내용은 계정 및 데이터 삭제 안내를 참고하세요.
