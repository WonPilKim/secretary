말비서 (개발자: 원앤컴퍼니)

앱에서 바로 삭제하기

  1. 말비서 앱을 열고 로그인합니다.
  2. 아래쪽 설정 탭으로 이동합니다.
  3. 맨 아래 회원 탈퇴를 누릅니다.
  4. 비밀번호를 입력하고 영구 삭제를 누릅니다.

삭제는 즉시 처리됩니다.

앱을 쓸 수 없는 경우 (이메일 요청)

앱을 지웠거나 휴대폰을 잃어버렸다면 아래 이메일로 요청해 주세요.

받는 곳: cosimprogram@gmail.com
제목: 말비서 계정 삭제 요청
내용: 가입한 이메일(또는 아이디)과 이름

본인 확인 후 7일 이내에 삭제하고 결과를 회신해 드립니다.

계정은 두고 일부 데이터만 삭제하기

계정을 지우지 않고 원하는 데이터만 지울 수도 있습니다. 앱에서 지우면 서버에서도 즉시 삭제됩니다.

  • 메모: 메모 탭 → 메모 오른쪽 휴지통(삭제) 버튼
  • 회의록: 회의록 탭 → 회의록 선택 → 위쪽 휴지통(삭제) 버튼
  • 일정: 일정 탭 → 일정 선택 → 위쪽 휴지통(삭제) 버튼
  • Claude API 키: 설정 탭 → API 키 칸을 비우고 저장

삭제되는 데이터 (회원 탈퇴 시)

  • 계정 정보: 이름, 이메일(또는 아이디), 비밀번호(로그인 정보)
  • 작성한 모든 메모, 회의록(받아쓴 텍스트·요약), 일정
  • 휴대폰에 저장된 설정(Claude API 키 등)과 예약된 일정 알림 (앱에서 탈퇴한 경우)

삭제된 데이터는 복구할 수 없습니다.
