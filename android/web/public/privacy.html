개인정보처리방침

시행일: 2026년 11월 20일

말비서(이하 "앱")를 운영하는 김원필(이하 "운영자")은 「개인정보 보호법」 등 관련 법령을 지키며, 이용자의 개인정보를 아래와 같이 처리합니다.

2. 음성 데이터 처리

  • 마이크 권한은 이용자가 음성 입력이나 회의 기록을 시작할 때만 사용합니다.
  • 음성은 휴대폰에 설치된 음성 인식 서비스(일반적으로 Google 음성 인식)가 텍스트로 바꿉니다. 이 과정에서 음성이 해당 서비스 제공자에게 전송될 수 있으며, 그 처리는 제공자의 개인정보처리방침을 따릅니다.
  • 앱은 녹음 파일(음성 원본)을 저장하지 않습니다. 인식된 텍스트만 저장합니다.

3. 회의록 요약

  • 무료 요약(기본): 휴대폰 안에서만 처리하며 외부로 전송하지 않습니다.
  • Claude AI 요약(선택): 이용자가 설정에 본인의 Claude API 키를 직접 입력한 경우에만, 요약할 회의 제목과 녹취 텍스트를 Anthropic(미국)에 전송합니다. API 키는 해당 휴대폰에만 저장되며 서버로 보내지 않습니다.

5. 보유 기간과 파기

  • 개인정보는 회원 탈퇴 시까지 보관합니다.
  • 고객지원 문의 내용과 이메일은 처리 완료 후 1년 이내에 삭제합니다.
  • 이용자가 메모·회의록·일정을 삭제하면 즉시 서버에서 삭제됩니다.
  • 회원 탈퇴 시 계정과 모든 메모·회의록·일정을 즉시 영구 삭제합니다. 방법은 계정 및 데이터 삭제 안내를 참고하세요.

6. 이용자의 권리

이용자는 언제든지 앱에서 자신의 정보를 조회·수정·삭제할 수 있고, 회원 탈퇴로 처리 정지를 요청할 수 있습니다. 앱에서 처리하기 어려운 경우 아래 연락처로 요청하시면 지체 없이 처리합니다.

7. 안전성 확보 조치

  • 모든 통신은 암호화(HTTPS/TLS)됩니다.
  • 서버 보안 규칙으로 로그인한 본인만 자신의 데이터에 접근할 수 있습니다.
  • 홈페이지의 내 기록 보기에 로그인하면, 로그인 상태를 유지하기 위한 인증 정보(토큰)를 브라우저에 저장합니다. "로그인 상태 유지"를 선택하지 않으면 브라우저 창을 닫을 때 지워지고, 로그아웃하면 즉시 지워집니다. 비밀번호는 브라우저에 저장하지 않습니다.
